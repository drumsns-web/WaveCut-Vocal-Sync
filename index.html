歌声トラックのズレ補正 0 ms

歌声が遅れて聞こえる場合はマイナス方向、歌声が早い場合はプラス方向に動かします。MIX時にもこの補正値を反映します。

コーラストラックのズレ補正 0 ms

コーラスもボーカルと同じように、カラオケ音源に対して前後へ動かせます。
