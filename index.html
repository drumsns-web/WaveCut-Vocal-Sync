操作 Vocal Sync

再生位置 00:00.000
カラオケ音源を読み込んでください。録音時はイヤホン推奨です。

1. カラオケ音源 Audio / Video

未選択
音源を持っていない場合 Mic Capture
別の端末・店内カラオケ・スピーカー等で鳴っているカラオケ音源を、マイクで一度録音して伴奏トラックにできます。
推奨：有線イヤホンで伴奏を聴きながら録音してください。スピーカー再生だと、伴奏がマイクに入り「歌声だけ録音」になりません。
MOV対策：iPhoneカメラロールのMOVは、直接デコードできない場合にWaveCut方式の「動画を再生しながら音声だけ取り込み」を使います。取り込み中は画面を閉じないでください。

2. マイク・録音設定 Mic OFF設計

カウントイン設定 非表示中
カラオケ音源を聴きながら歌う用途では、カウントインは基本OFFで問題ありません。必要な時だけ表示して設定できます。
マイク入力
MIX出力目安
マイクON/OFFは別ボタンです。ページ表示中に常時ONにはしません。録音開始時に必要ならON、停止後にOFFへ戻します。

3. 波形でズレ補正 Vocal Sync

Track 1：カラオケ音源
未読込
Track 2：歌声録音
未録音
通常は歌声波形を左右にドラッグしてズレ補正。範囲編集を押すと、ドラッグで選択範囲を作れます。歌が遅れて聞こえる → 左へ / 歌が早い → 右へ
歌声のズレ補正 0ms

4. 歌声の範囲編集 未選択

編集対象は歌声トラックです。波形の一部だけを選び、切り取り・削除・コピー・ペースト・部分エフェクトをかけられます。

5. MIX設定 簡単ミキサー

おすすめ初期値：伴奏82%、歌声108%、ボーカル音色ナチュラル、リバーブ12%、ディレイ6%、初期補正-80ms。録音後に波形と耳で微調整してください。

使い方 Workflow

1. カラオケ音源を読み込む → 2. イヤホンを付ける → 3. 「歌を録音」 → 4. MIX再生で確認 → 5. 歌声を左右に動かしてズレ補正 → 6. 必要なら範囲編集・部分エフェクト → 7. MIX保存。
カラオケ音源を持っていない場合は、外部で鳴っているカラオケをマイクで録音して伴奏トラックにできます。MP4は通常読み込みを試し、失敗した場合はWaveCut方式の音声取り込みに切り替えます。Bluetoothイヤホンは遅延が大きい場合があります。有線イヤホンの方が波形合わせが楽です。
設定
Count-in
カウントイン項目をメイン画面に表示普段は非表示推奨。必要な時だけONにしてください。
現在のカウント設定
設定を表示した後、メイン画面の「マイク・録音設定」内でカウントインの拍数・表示・BPMを変更できます。カラオケ音源を聴きながら歌う通常用途では「なし」のままで大丈夫です。
